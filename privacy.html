Datenschutz

Screniva ist ein nativer Screencast-Editor für den Mac. Diese Erklärung beschreibt, welche Daten die App verarbeitet und wann (optional) Netzwerkzugriff entsteht.

Kurz gesagt

Projekte und Aufnahmen bleiben auf deinem Mac. Kein Tracking, keine Analytics-SDKs, kein werbliches Profiling. Optionale Cloud-Funktionen nur, wenn du sie aktivierst.

Verantwortlicher

Christoph Bordeck
Kontakt: support@screniva.app

Speicherorte auf dem Gerät

  • Direct Distribution: Projekte unter ~/Movies/Screniva/
  • Mac App Store (Sandbox): Projekte unter dem Application-Support-Ordner der App (Sandbox-Container)
  • Lokale Diagnose-Logs und Crash-Notizen (bis du ein Support-Paket exportierst)

Welche Daten entstehen

  • Bildschirm-, Fenster- oder Bereichsaufnahmen
  • Optional Mikrofon-, Systemton- und Facecam-/Webcam-Aufnahmen
  • Timeline, Overlays, Cursor-Track, Untertitel, Kapitel und Exporte
  • App-Einstellungen (lokal, z. B. über UserDefaults)

Diese Inhalte dienen der App-Funktion. Sie werden nicht an Screniva-Server gesendet und nicht mit einer Nutzeridentität verknüpft.

Berechtigungen (macOS)

  • Bildschirmaufnahme (ScreenCaptureKit) — für Screencasts
  • Mikrofon — nur wenn du Ton aufnimmst
  • Kamera — nur für optionale Facecam (inkl. Continuity Camera)
  • Spracherkennung — für Untertitel auf dem Gerät

Optionaler Netzwerkzugriff

  • Cloud-TTS (OpenRouter): nur wenn du einen API-Key hinterlegst und Cloud-TTS erlaubst. Dann wird Text zur Sprachsynthese an openrouter.ai gesendet. MDM kann das abschalten (screniva.managed.cloudTTSDisabled=true).
  • iCloud-Sync: nur wenn Sync in den Einstellungen aktiviert ist. Dann können Projekte über deinen Apple-iCloud-Account gespiegelt werden.
  • Untertitel (ASR): bevorzugt on-device. Ein Legacy-Fallback kann Apple-Server nutzen, wenn die lokale Erkennung kein Ergebnis liefert.
  • Update-Check (Direct Distribution): optionaler Abruf eines JSON-Feeds unter https://chbrdk.github.io/screniva-site/appcast.json. Die Mac-App-Store-Version nutzt Apples Update-Kanal statt dieses Feeds.

Support-Paket

Über Hilfe → Support-Paket erstellen… kannst du lokal Version, Feature-Flags und Diagnose-Logs exportieren (ohne Secrets und ohne Mediendateien). Dieses Paket verlässt dein Gerät nur, wenn du es selbst versendest.

Keine Tracking-Technologien

Screniva enthält keine Tracking-SDKs, keine Werbe-IDs und keine Analytics-Dienste von Drittanbietern zum Nutzerprofilieren.

Website

Diese Produktseite (GitHub Pages) stellt Informationen und Downloads bereit. Es werden keine zusätzlichen Analyse-Cookies durch Screniva gesetzt. Beim Hosting können serverübliche Zugriffsprotokolle (z. B. IP, User-Agent) beim Anbieter anfallen — das liegt außerhalb der App.

Privacy Policy

Screniva is a native screencast editor for Mac. This policy explains what data the app processes and when optional network access occurs.

In short

Projects and recordings stay on your Mac. No tracking, no analytics SDKs, no advertising profiling. Optional cloud features only when you turn them on.

Controller

Christoph Bordeck
Contact: support@screniva.app

On-device storage

  • Direct Distribution: projects under ~/Movies/Screniva/
  • Mac App Store (Sandbox): projects under the app’s Application Support container
  • Local diagnostic logs and crash notes (until you export a support package)

Data created by the app

  • Screen, window, or region recordings
  • Optional microphone, system audio, and facecam/webcam recordings
  • Timeline, overlays, cursor track, captions, chapters, and exports
  • App preferences stored locally (e.g. UserDefaults)

This content is used for app functionality. It is not sent to Screniva servers and is not linked to a user identity by us.

Permissions (macOS)

  • Screen Recording (ScreenCaptureKit) — for screencasts
  • Microphone — only when you record audio
  • Camera — only for optional facecam (including Continuity Camera)
  • Speech Recognition — for on-device captions

Optional network access

  • Cloud TTS (OpenRouter): only if you add an API key and allow Cloud TTS. Text is then sent to openrouter.ai for speech synthesis. MDM can disable this (screniva.managed.cloudTTSDisabled=true).
  • iCloud Sync: only if enabled in Settings. Projects may then sync via your Apple iCloud account.
  • Captions (ASR): prefers on-device recognition. A legacy fallback may use Apple servers if local recognition returns no result.
  • Update check (Direct Distribution): optional fetch of a JSON feed at https://chbrdk.github.io/screniva-site/appcast.json. The Mac App Store build uses Apple’s update channel instead.

Support package

Help → Create Support Package… exports version info, feature flags, and diagnostic logs locally (no secrets, no media files). It leaves your device only if you send it.

No tracking

Screniva does not include tracking SDKs, advertising identifiers, or third-party analytics for user profiling.

Website

This product site (GitHub Pages) provides information and downloads. Screniva does not set additional analytics cookies. Hosting providers may keep standard access logs (e.g. IP, user agent) outside the app.
